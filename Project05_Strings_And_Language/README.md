
# Project - Strings and Language

Programs focused on string manipulation and randomness.

## 1. randomSentence.c
Generates random sentences using words selected from arrays (articles, nouns, verbs, prepositions).

## 2. latinPig.c
Converts an English phrase into a simplified form of Pig Latin using `strtok` and character shifting.

## Compile and Run Example:
```bash
gcc filename.c -o program
./program
```
