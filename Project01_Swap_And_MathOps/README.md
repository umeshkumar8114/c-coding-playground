
# Assignment 1 - COP 3514

Three short C programs focusing on fundamental programming and math concepts.

## 1. interview.c
Swap two integers without using a third variable using arithmetic operations.

## 2. newtons_laws.c
Calculate gravitational forces between celestial bodies using Newton’s Law of Universal Gravitation.

## 3. shapesInCircle.c
Compute area and perimeter for a circle, and for a square/triangle inscribed within it.

## Compile and Run Example:
```bash
gcc filename.c -o program
./program
```
