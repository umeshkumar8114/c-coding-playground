
# Project - Pointers and Grades

Two programs using pointer notation and dynamic memory allocation.

## 1. linearSearch.c
Reads 10 integers and searches for a user-specified value using pointer arithmetic (no array indexing).

## 2. gradeChecker.c
Calculates a weighted final grade from 6 assignments, a midterm, and a final exam using dynamic memory and functions.

## Compile and Run Example:
```bash
gcc filename.c -o program
./program
```
