# Project ASCII and Date Tools

Three beginner-friendly C programs focused on input validation, ASCII character handling, and day-of-week calculations.

## 1. character_lookup.c  
Prompts the user for a number (32–126) and displays its corresponding ASCII character.

## 2. future_dates.c  
Calculates the future day of the week based on the current day and an offset using modulo logic and `switch` statements.

## 3. pythagorean_triple.c  
Finds and displays all Pythagorean triples up to a user-defined hypotenuse using nested loops and the Pythagorean theorem.
