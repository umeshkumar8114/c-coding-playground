
# Project - Primes and Unique Data

Two programs demonstrating array manipulation and basic algorithmic logic.

## 1. eliminate_duplicates.c
Reads 15 integers from the user and stores only the unique values, filtering out duplicates in real-time.

## 2. sieve.c
Implements the Sieve of Eratosthenes to find and display all prime numbers up to a user-defined limit.

## Compile and Run Example:
```bash
gcc filename.c -o program
./program
```
