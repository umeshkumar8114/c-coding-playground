
# C Fundamentals Projects

A curated collection of beginner-to-intermediate level C programming projects focused on practical problem solving, logic building, and system-level programming basics.

Each folder contains one or more small programs that demonstrate specific areas of the C language, such as:

- File I/O
- Pointers and dynamic memory
- String manipulation
- Arrays and structures
- Modular code design

This collection serves as a portfolio of hands-on C code — ideal for building confidence in low-level programming and data handling.

Feel free to explore and run the programs!
